# Ложные пропуски: эвристики эквивалентности, шума, subsumed/owned, timeout и дубли

> Раздел 2 («Ложные пропуски») анализа Mootant, коммит 170ec52. Диапазон ID —
> BUG-300…BUG-399. Статус документа: **промежуточный** (эмпирическая выборка
> ещё считается; таблица по правилам будет дополнена).

## Резюме (промежуточное)

Статический разбор правил пропуска и фикстуры нашли **10 классов ложных
пропусков**, все подтверждены воспроизведением (фикстура + `mootant run` с
100 % при физически выживающем пропущенном мутанте, или падающий тест в
`experiment/bug-repros`):

- `solitary` (34 % всех пропусков) ломается на двух частых шаблонах:
  опустошённая строка в элементе множества/списка (BUG-300) и локальная
  переменная, которую функция читает ещё где-то, кроме `return` (BUG-301).
- Правила, заявленные как доказательные (`heuristic: false`), тоже ошибаются:
  `O19` считает удаление then-ветки «тем же мутантом», что `if (false)`, даже
  если условие с эффектом (BUG-302); `R6` — то же, что BUG-301, для булевых
  констант (BUG-304); `loop-advance` (timeout) считает продвижением цикла любой
  вызов метода у корня имени из условия, `items[i].render()` (BUG-303).
- `--since` отбирает мутантов по строкам **после** правил пропуска: если
  владелец пропуска на неизменённой строке, изменённая строка остаётся без
  мутантов (BUG-305, high) — это основной CI-сценарий.
- Эквивалентность нарушается на `NaN`: `done / total || 0` → `done / total`
  помечен `equivalent` (BUG-307); `value + 0` → `value - 0` при неизвестном
  типе (BUG-308).
- Шум: коды ошибок в аргументах `new XError('NOT_FOUND', …)` (BUG-306) и все
  строки JSX-атрибутов, включая `type="password"`, `aria-label`, `href`
  (BUG-309).

## Находки по ходу работы

- BUG-300 (solitary, string-literal внутри элемента массива/свойства) — подтверждён фикстурой
  `analysis/data/skips/fx1` (`src/keywords.js`): `mootant run` даёт 100 %, физическое удаление
  `'else'` из `new Set(['if', 'else', 'for'])` переживает тесты.
- BUG-301 (solitary, return-value с локальной переменной) — подтверждён (`src/process.js`):
  `return count` → `return 0` пропущен из-за `let count = 0` → `1`, который убивается через
  колбэк; физически применённый мутант выживает.
- BUG-302 (O19: удаление then-ветки ≠ `if (false)`, если у условия есть побочный эффект) —
  подтверждён (`src/remove.js`, `if (map.delete(key)) onRemove(key)`).
- BUG-303 (loop-advance: вызов метода у элемента массива, который читает условие цикла, принят за
  продвижение цикла) — подтверждён (`src/render.js`: `items[i].render()` в `for (i < items.length)`;
  удаление пропущено как timeout, физически завершается за 0.8 с и выживает; `mootant run` = 100 %).
- BUG-304 (R6: `return ok` → `true/false` «поглощён» мутантом инициализатора `ok`, хотя `ok`
  читается ещё и в `if (!ok) report(...)`) — подтверждён (`src/validate.js`: 100 % при
  физически выживающих `return true` и `return false`).
- BUG-305 (`--since`: отбор по изменённым строкам после генерации; пропуск, чей владелец на
  неизменённой строке, не возвращается) — подтверждён (`analysis/data/skips/fx-since`:
  `mutants 0`, `score none`; падающий тест `test/repros/BUG-305.test.ts`). В зоне риска 726
  пропусков core и 420 perfectionist (O19, R4, R5, R6, solitary с владельцем на другой строке).
  Документация (`docs/content/mutators/statement-removal.md:222`) обещает, что `solitary` и `R4`
  возвращаются, «when the other mutant doesn't run» — с `--since` это не так.
- BUG-306 (error-message: код ошибки в аргументах конструктора `*Error` принят за текст
  сообщения) — подтверждён (`src/errors.js`: `throw new AppError('NOT_FOUND', ...)`, `statusOf`
  сравнивает код; 100 % при выживающем `'NOT_FOUND'` → `''`). low: эвристика помечена, в core и
  perfectionist таких кодов нет.
- BUG-307 (canonical-falsy-default: `done / total || 0` и `Number(text) || 0` → удаление `|| 0`
  считается эквивалентным, хотя отличается на `NaN`) — подтверждён (`src/nan.js`: все мутанты
  `ratio`/`toCount` убиты, физически выживают оба пропущенных; `ratio(0, 0)` 0 → NaN).
- BUG-308 (numeric-identity: `value + 0` → `value - 0` пропущен как эквивалентный при неизвестном
  типе `value`; JSDoc `getSwapSkip` (`core/mutators/arithmetic-operator.ts:79-80`) обещает
  проверку числового типа «для + и -», код проверяет только `-` (`:98`)) — подтверждён листингом
  и тестом; `'7' + 0` = `'70'`, `'7' - 0` = `7`. low.
- BUG-309 (jsx-attribute: все строки JSX-атрибутов — шум, включая `type="password"`,
  `aria-label`, `href`) — подтверждён листингом/тестом (`analysis/data/skips/fx3/src/Login.jsx`).
  Политика, но документирована только на примере `className`; опции нет.
