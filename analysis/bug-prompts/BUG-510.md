# BUG-510: node:test — проба Node падает со стеком, если `NODE_OPTIONS` подгружает печатающий модуль

> Самодостаточный промпт для отдельной сессии Claude Code в репозитории
> azat-io/mootant. Серьёзность: medium. Статус: подтверждён. Найдено на
> коммите 170ec52.

## Контекст

При старте сессии node:test (`adapters/node-test/start-node-test-session.ts:72`)
mootant узнаёт версию Node и поддержку type stripping:
`readNodeRuntime` (`adapters/node-test/read-node-runtime.ts:18-33`) запускает
`node -p PROBE` с окружением mootant, то есть и с `NODE_OPTIONS` проекта, и
делает `JSON.parse(stdout)` прямо в колбэке `execFile` (`:22-24`). Если
`NODE_OPTIONS` подгружает модуль, который пишет в stdout (свой preload,
инструментирование, вероятно `-r dotenv/config` у dotenv 17), stdout
начинается не с JSON, `JSON.parse` бросает исключение вне промиса: процесс
mootant падает с `SyntaxError` и стеком вместо понятного сообщения, промис
никогда не завершается. Для таких проектов node:test-прогон невозможен.

## Воспроизведение

Падающий тест в ветке `experiment/bug-repros`: `test/repros/BUG-510.test.ts`.

```ts
import { afterEach, describe, expect, it } from 'vitest'
import { mkdtemp, writeFile, rm } from 'node:fs/promises'
import { tmpdir } from 'node:os'
import path from 'node:path'

import { readNodeRuntime } from '../../adapters/node-test/read-node-runtime'

let originalOptions = process.env['NODE_OPTIONS']
let directory: string | null = null

describe('BUG-510: node:test probe with a preload that prints', () => {
  afterEach(async () => {
    if (originalOptions === undefined) {
      delete process.env['NODE_OPTIONS']
    } else {
      process.env['NODE_OPTIONS'] = originalOptions
    }
    if (directory !== null) {
      await rm(directory, { recursive: true, force: true })
      directory = null
    }
  })

  it('reads the runtime when NODE_OPTIONS preloads a module that prints', async () => {
    directory = await mkdtemp(path.join(tmpdir(), 'mootant-print-'))
    let preload = path.join(directory, 'print.cjs')
    await writeFile(preload, "console.log('[preload] hello')\n")
    process.env['NODE_OPTIONS'] = `--require ${preload}`

    await expect(readNodeRuntime(process.execPath)).resolves.toMatchObject({
      version: process.version,
    })
  })
})
```

Сквозное воспроизведение на любой фикстуре node:test (`"test": "node --test"`):

```bash
printf "console.log('[preload] hello')\n" > print.cjs
NODE_OPTIONS="--require ./print.cjs" npx mootant run src
```

## Ожидаемое поведение

Проба читает версию и признак type stripping, игнорируя постороннюю печать
(например, по последней строке stdout или по маркеру), а при любой ошибке
разбора промис отклоняется с понятным `Error`, который CLI печатает как
`Error: …` с кодом 1.

```

<anonymous_script>:1

SyntaxError: Unexpected token 'p', "[preload] h"... is not valid JSON
    at JSON.parse (<anonymous>)
    at file:///…/node_modules/mootant/dist/adapters/node-test/read-node-runtime.js:6:23
    at ChildProcess.exithandler (node:child_process:410:7)
```

Тест: таймаут 5 с и «Unhandled Errors: SyntaxError …».

## Подозреваемые места в коде

- `adapters/node-test/read-node-runtime.ts:22-31` — разбор stdout без
  `try/catch` в колбэке; печать проб можно отделить маркером или читать
  последнюю строку.
- `adapters/node-test/start-node-test-session.ts:72` — вызов пробы.

## Критерий готовности

- Тест в `test/adapters/node-test/read-node-runtime.test.ts`: печать preload до
  JSON не мешает прочитать версию; непарсируемый вывод даёт отклонённый промис
  с `Error`; падает до исправления, проходит после.
  `test/repros/BUG-510.test.ts` проходит.
- `pnpm test` полностью зелёный (включая 100% coverage, `test:js`,
  `test:types`, `test:usage`, `test:spelling`).
