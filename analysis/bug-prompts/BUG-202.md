# BUG-202: `--fast` окончательно записывает в Timeout «горячий» конечный цикл, который режим по умолчанию считает выжившим

> Самодостаточный промпт для отдельной сессии Claude Code в репозитории
> azat-io/mootant. Серьёзность: medium. Статус: подтверждён.
> Найдено на коммите 170ec52.

## Контекст

В batch-пути (`--fast`) лимит срабатываний сайтов считается на одну попытку
теста: `max(100000, 100 × hits этого теста в dry run)`
(`core/run/plan-batch.ts:92-96`, `core/run/get-try-limits.ts:16-28`), а
превышение даёт окончательный `Timeout(hit-limit)` без перепроверки
(`core/run/apply-batch-result.ts:163-171`; принимается при хороших контрольных
попытках, `:305-320`). В isolated-пути лимит юнита — *сумма* лимитов всех
тестов файла плюс загрузка (`core/run/plan-isolated.ts:16-44`), то есть в N
раз больше для файла из N тестов. Мутант, который превращает дешёвый тест в
конечный, но «горячий» цикл на ~10⁵ вычислений сайтов, в режиме по умолчанию
проходит (и эталон — обычный прогон Vitest — тоже), а в `--fast` получает
`Timeout`, засчитанный в score. Документация предупреждает, что в fast mode
«a kill may be false», но о ложных Timeout и о том, что batch-Timeout не
перепроверяется, не говорит (`docs/content/guide/configuration.mdx`, `fast`).
Родственная, но отдельная проблема — BUG-200 (лимит слишком мал вообще).

## Подозреваемые места в коде

- `core/run/apply-batch-result.ts:163-171` — `hit-limit` в batch окончателен,
  в отличие от `time-limit`, который ждёт подтверждения.
- `core/run/plan-batch.ts:92-96` — лимит попытки — только по своему тесту, без
  запаса, который есть у isolated-юнита.

## Критерий готовности

- `test/repros/BUG-202.test.ts` проходит; регрессионный тест рядом с
  существующими тестами batch (`test/core/run/apply-batch-result.test.ts`)
  проверяет, что batch-Timeout по `hit-limit` уходит на isolated-путь (или
  подтверждается с лимитом, не меньшим лимита isolated-юнита).
- Мутант с настоящим бесконечным циклом (`index++` → `index--`) по-прежнему
  `Timeout` в обоих режимах.
- `pnpm test` полностью зелёный (включая 100% coverage, `test:js`,
  `test:types`, `test:usage`, `test:spelling`).
