# BUG-905: одна неразбираемая замена превращает весь прогон в Error

> Самодостаточный промпт для отдельной сессии Claude Code в репозитории
> azat-io/mootant. Серьёзность: medium. Статус: подтверждён.
> Найдено на коммите 170ec52.

## Контекст

Мутаторы — ESLint-подобные правила, в том числе из плагинов. Узел замены
проверяется (`core/generate/validate-replacement.ts:132-167`), а текст — нет:

- `groupReplacement` разбирает текст (`readText`) и, если тот не разбирается
  ни в одном контексте, только оборачивает его в скобки
  (`core/generate/group-replacement.ts:233-236`);
- `addReplacement` (`core/generate/collect-candidates.ts:266-367`) принимает
  такой кандидат; `mootant list` показывает его как обычный мутант;
- `createSwitchedFiles`/`instrumentFile` не разбирают переключённый текст
  (`core/instrument/create-switched-files.ts:74-94`, проверка компиляции есть
  только для Svelte/Vue).

В dry run тест-файл, импортирующий такой файл, падает при загрузке до
вычисления любого сайта (`covers: []`). `findBrokenFiles` при пустом множестве
подозреваемых объявляет сломанными все переключённые файлы
(`core/run/run-dry-phase.ts:505-517`, строка 516), и мутанты всех файлов
прогона получают `Error` с сообщением «Tests fail with the switched <file> and
pass without it» — в том числе файлы, которые ничего не ломали.

## Воспроизведение

Юнит-тест (ветка `experiment/bug-repros`, `test/repros/BUG-905.test.ts`):

```ts
import { describe, expect, it } from 'vitest'

import type { DryRunResult } from '../../types/adapter/dry-run-result'
import type { SwitchedFile } from '../../types/adapter/switched-file'
import type { FakeWorld } from '../helpers/create-fake-adapter'

import { createSwitchedFiles } from '../../core/instrument/create-switched-files'
import { createFakeAdapter } from '../helpers/create-fake-adapter'
import { runDryPhase } from '../../core/run/run-dry-phase'
import { createMutant } from '../helpers/create-mutant'

describe('BUG-905', () => {
  it('reports the file whose switched text does not parse instead of serving it', () => {
    let math = 'export function add(a, b) {\n  return a + b\n}\n'
    let other = "export function greet(name) {\n  return 'Hello, ' + name\n}\n"
    let built = createSwitchedFiles([
      {
        mutants: [createMutant({ file: 'src/math.js', replacement: 'a +', start: 37, end: 42 })],
        absolute: '/p/src/math.js',
        file: 'src/math.js',
        source: math,
      },
      {
        mutants: [createMutant({ replacement: "'Hello, '", file: 'src/other.js', start: 39, id: 'm2', end: 55 })],
        absolute: '/p/src/other.js',
        file: 'src/other.js',
        source: other,
      },
    ])
    expect(built.diagnostics.map(diagnostic => diagnostic.file)).toStrictEqual(['src/math.js'])
    expect(built.switched.map(entry => entry.file)).toStrictEqual(['/p/src/other.js'])
  })

  it('does not blame a switched file that no failing test file reached or loaded', async () => {
    let world: FakeWorld = {
      onDry: (result: DryRunResult, request) =>
        request.instrumented ?
          {
            ...result,
            files: result.files.map(file =>
              file.file === '/t/a.test.ts' ?
                { ...file, errors: ['SyntaxError: Unexpected token'], loadFailed: true, covers: [] }
              : file,
            ),
            tests: result.tests.filter(test => test.file !== '/t/a.test.ts'),
          }
        : result,
      tests: [
        { file: '/t/a.test.ts', covers: ['a1'], id: 'ta' },
        { file: '/t/b.test.ts', covers: ['b1'], id: 'tb' },
      ],
    }
    let fake = createFakeAdapter(world)
    let switched: SwitchedFile[] = [
      { switched: 'hit("a1")', file: '/src/a.ts', original: '' },
      { switched: 'hit("b1")', file: '/src/b.ts', original: '' },
    ]
    let session = await fake.adapter.start({ workDirectory: '/work', concurrency: null, files: switched, root: '/' })
    let phase = await runDryPhase(session, {
      displays: new Map([['/src/a.ts', 'src/a.ts'], ['/src/b.ts', 'src/b.ts']]),
      mutantFiles: new Map([['a1', '/src/a.ts'], ['b1', '/src/b.ts']]),
      report: () => {},
      repeat: false,
      root: '/',
      switched,
    })
    expect([...phase.errors.keys()]).not.toContain('src/b.ts')
  })
})
```

  mutators: { 'acme/broken': 'on' },

и двумя файлами `src/math.js` (`return a + b`), `src/other.js`

`error 4`, в том числе оба мутанта `src/other.js` с «Tests fail with the
switched src/other.js and pass without it».

## Ожидаемое поведение

- Неразбираемый текст замены — ошибка мутатора (`mutator-error` с позицией,
  кандидат пропущен), как нарушение `validateReplacement`; либо переключённый
  файл, который не разбирается, получает `instrument-error` и не отдаётся.
- Отказ загрузки без покрытия не обвиняет файлы, которых упавший тест-файл не
  загружал: подозреваемые сужаются до `DryFile.dependencies` упавших файлов
  (поле есть у адаптера Vitest, `types/adapter/dry-file.d.ts:4-13`), а «все
  файлы» — только когда зависимости неизвестны.
- В сценарии выше мутанты `src/other.js` решаются как обычно.

## Фактическое поведение

Мутант с текстом `a +` попадает в список и в переключённый файл; в dry run все
переключённые файлы выбрасываются, все мутанты — `Error`, exit 1.

## Подозреваемые места в коде

- `core/generate/group-replacement.ts:233-236` — неразбираемый текст не
  отвергается.
- `core/generate/collect-candidates.ts:266-367` — `addReplacement`.
- `core/instrument/create-switched-files.ts:74-94` — нет разбора результата.
- `core/run/run-dry-phase.ts:505-517` — запасной вариант «сломаны все».

## Критерий готовности

- Тесты из `test/repros/BUG-905.test.ts` перенесены в `test/core/...` и
  проходят (первый — в форме, соответствующей выбранному месту проверки:
  генерация или переключение).
- Есть тест генерации: плагин-мутатор с неразбираемым текстом даёт ошибку
  мутатора, а не мутанта.
- Проверка не замедляет `mootant list` заметно (замер на `core`).
- `pnpm test` полностью зелёный (включая 100% coverage, `test:js`,
  `test:types`, `test:usage`, `test:spelling`).
