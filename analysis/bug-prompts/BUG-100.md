# BUG-100: провал dry run без достигнутых сайтов выбрасывает все switched-файлы

> Самодостаточный промпт для отдельной сессии Claude Code в репозитории
> azat-io/mootant. Серьёзность: medium. Статус: подтверждён.
> Найдено на коммите 170ec52.

## Контекст

Перед прогоном мутантов Mootant делает dry run: тесты запускаются на
switched-файлах (все мутанты захощены, ни один не активен). Если тесты падают,
`runDryPhase` (`core/run/run-dry-phase.ts:141-174`) перезапускает упавшие
тест-файлы без switched-файлов (`checkRealFailures`, `:385-421`); провалы, которые
исчезли, считаются вызванными инструментированием, и «виновные» switched-файлы
выбрасываются с ошибкой `instrumentation-break` — все их мутанты получают
`Error`, прогон завершается с кодом 1 (`recoverFromFailures`, `:275-296`).

Виновных выбирает `findBrokenFiles` (`core/run/run-dry-phase.ts:505-517`): это
файлы мутантов, чьи сайты достигли упавшие тесты и незагрузившиеся тест-файлы.
Если они не достигли ни одного сайта, функция объявляет сломанными **все**
switched-файлы прогона (`return broken.size === 0 ? new Set(related) : broken`,
строка 516). Так бывает, когда тест-файл падает до первого сайта: модуль не
трансформируется или бросает при загрузке до первой проверки сайта (например,
привязка с именем `globalThis`, BUG-101), `beforeAll` падает до вызова
кода, или тест-файл/хук нестабилен (port in use, ресурс не готов). Тогда
невиновные файлы получают ложную диагностику «Tests fail with the switched
src/price.js and pass without it», а весь прогон теряет вердикты.

Связанные находки других разделов: BUG-902 (один нестабильный провал
приписывается инструментированию) и BUG-905 (непарсящийся replacement
плагина ломает все файлы) — у BUG-905 та же строка 516 как причина
«все файлы».

## Воспроизведение

Юнит-тест в ветке `experiment/bug-repros`: `test/repros/BUG-100.test.ts`
(два кейса, оба падают на 170ec52). Код теста:

```ts
import { describe, expect, it } from 'vitest'

import type { DryRunResult } from '../../types/adapter/dry-run-result'
import type { SwitchedFile } from '../../types/adapter/switched-file'
import type { FakeWorld } from '../helpers/create-fake-adapter'

import { createFakeAdapter } from '../helpers/create-fake-adapter'
import { runDryPhase } from '../../core/run/run-dry-phase'

async function runPhase(
  failsWithB: (request: { instrumented: boolean; related: string[] }) => boolean,
): Promise<{ diagnostics: string[]; switched: string[] }> {
  let world: FakeWorld = {
    onDry: (result: DryRunResult, request) => {
      if (!failsWithB(request)) {
        return result
      }
      return {
        ...result,
        files: result.files.map(file =>
          file.file === '/t/b.test.ts'
            ? { ...file, errors: ['ReferenceError'], loadFailed: true, covers: [] }
            : file,
        ),
        tests: result.tests.filter(test => test.file !== '/t/b.test.ts'),
      }
    },
    tests: [
      { file: '/t/a.test.ts', covers: ['a1'], id: 'ta' },
      { file: '/t/b.test.ts', covers: ['b1'], id: 'tb' },
    ],
  }
  let fake = createFakeAdapter(world)
  let switched: SwitchedFile[] = [
    { switched: 'hit("a1")', file: '/src/a.ts', original: '' },
    { switched: 'hit("b1")', file: '/src/b.ts', original: '' },
  ]
  let session = await fake.adapter.start({
    workDirectory: '/work', concurrency: null, files: switched, root: '/',
  })
  let phase = await runDryPhase(session, {
    displays: new Map([['/src/a.ts', 'src/a.ts'], ['/src/b.ts', 'src/b.ts']]),
    mutantFiles: new Map([['a1', '/src/a.ts'], ['b1', '/src/b.ts']]),
    report: () => {}, repeat: false, root: '/', switched,
  })
  return {
    diagnostics: phase.diagnostics.map(d => `${d.code} ${d.file}`),
    switched: switched.map(entry => entry.file),
  }
}

describe('BUG-100', () => {
  it('keeps a switched file whose tests pass when another file breaks a test file before any site', async () => {
    let result = await runPhase(r => r.instrumented && r.related.includes('/src/b.ts'))
    expect(result.diagnostics).not.toContain('instrumentation-break src/a.ts')
    expect(result.switched).toContain('/src/a.ts')
  })

  it('drops no file when a test file failed to load once, before any site, and loads when run again', async () => {
    let runs = 0
    let result = await runPhase(r => r.instrumented && ++runs === 1)
    expect(result.diagnostics).toStrictEqual([])
    expect(result.switched).toStrictEqual(['/src/a.ts', '/src/b.ts'])
  })
})
```

## Ожидаемое поведение

- Файл, без которого провал не исчезает (или провал не воспроизводится),
  не получает `instrumentation-break`; его мутанты прогоняются.
- В collateral выбрасывается только `src/env.js`; в flaky — ничего (или
  прогон явно сообщает о нестабильном тесте), `src/price.js` прогоняется
  в обоих случаях.

## Фактическое поведение

flaky:      {"errorMutants":12,"mutants":12,"dropped":["src/format.js","src/price.js"]}

Второй прогон flaky (маркер уже есть): 9 killed, 3 survived, ошибок нет.

## Подозреваемые места в коде

- `core/run/run-dry-phase.ts:516` — `broken.size === 0 ? new Set(related)`:
  без улик виноватыми объявляются все файлы.
- `core/run/run-dry-phase.ts:385-421` (`checkRealFailures`) — «реальность»
  провала проверяется одним прогоном без switched-файлов; провал, который не
  повторился, без повторного instrumented-прогона приписывается
  инструментированию (см. также BUG-902).
- `core/run/run-dry-phase.ts:275-296` — все найденные файлы удаляются разом,
  диагностика утверждает, что тесты «fail with the switched <file>».

Направление: при пустом наборе улик (а) сначала повторить упавшие тест-файлы с
теми же switched-файлами; если провал не повторяется — считать его нестабильным
(предупреждение, без выбрасывания); (б) если повторяется — сузить множество
(бисекция по switched-файлам, которые импортирует упавший тест-файл, или по
одному файлу), выбрасывать только те, без которых провал исчезает.

## Критерий готовности

- Тест `test/core/run/run-dry-phase.test.ts` (или перенесённый
  `test/repros/BUG-100.test.ts`) с обоими кейсами падает до исправления и
  проходит после.
- `test/repros/BUG-100/run.sh` на собранном пакете: в collateral выброшен
  только `src/env.js`, в flaky ничего не выброшено, `src/price.js` имеет
  вердикты Killed/Survived.
- `pnpm test` полностью зелёный (включая 100% coverage, `test:js`,
  `test:types`, `test:usage`, `test:spelling`).
- Число дополнительных dry-прогонов ограничено (например, не больше
  ⌈log2 N⌉+1 при бисекции N файлов) и отражено в прогрессе (`dry-again`).
