# BUG-402: кэш не видит файлы, от которых зависят виртуальные модули Vite

> Самодостаточный промпт для отдельной сессии Claude Code в репозитории
> azat-io/mootant. Серьёзность: medium. Статус: подтверждён.
> Найдено на коммите 170ec52.

## Контекст

Кэш вердиктов (`core/cache/*`) переиспользует вердикт мутанта, пока не
изменились мутируемый файл и всё, от чего зависит тестовый файл. Список
зависимостей Vitest строит `collectDependencies`
(`adapters/vitest/collect-dependencies.ts:76-155`): модули, вычисленные
воркером, и всё, что они достигают в графе модулей Vite, «which takes in files
plugins watch» (`adapters/vitest/collect-dependencies.ts:58-64`, контракт
`types/adapter/dry-file.d.ts:6-9`). Но виртуальные модули (`\0virtual:…`,
`virtual:…`) выбрасываются целиком: `add()` возвращает `false` для любого id,
который не является абсолютным путём (`adapters/vitest/collect-dependencies.ts:93-100`,
`adapters/vitest/get-module-file.ts:17-20`), и такой узел не обходится ни как
корень (`:131-134`), ни как промежуточный (`:121-124`). Плагин, который строит
виртуальный модуль из файла и вызывает `this.addWatchFile(file)`, получает этот
файл в `importedModules` виртуального модуля (так делает `vite:import-analysis`
в Vite 8), но mootant до него не доходит. После правки файла кэш возвращает
**старые вердикты в обе стороны** — ложный `Survived` и ложный `Killed`, без
всякого предупреждения и без `--incremental`. Так устроены плагины, которые
встраивают содержимое файла (данные, конфиги, сгенерированные списки) в
виртуальный модуль; плагины, генерирующие `import` реальных файлов, не
затронуты — эти файлы воркер вычисляет и сообщает сам. Плагины, которые читают
файлы и не объявляют их через `addWatchFile`, исправление не покроет — это
стоит описать в документации рядом с оговоркой про дочерние процессы
(`docs/content/guide/configuration.mdx:357-359`).


Создай `test/repros/BUG-402.test.ts` и запусти
`pnpm vitest run test/repros/BUG-402.test.ts --coverage.enabled=false`
(оба теста падают на 170ec52):

```ts
import type { TestProject } from 'vitest/node'

import { writeFile, realpath, mkdtemp, symlink, mkdir, rm } from 'node:fs/promises'
import { afterEach, describe, expect, it } from 'vitest'
import { setTimeout } from 'node:timers/promises'
import { tmpdir } from 'node:os'
import path from 'node:path'

import type { RunResult } from '../../types/run/run-result'

import { collectDependencies } from '../../adapters/vitest/collect-dependencies'
import { createBuiltIns } from '../helpers/create-built-ins'
import { vitestAdapter } from '../../adapters/vitest/index'
import { runMutants } from '../../core/run-mutants'

let roots: string[] = []

async function write(root: string, files: Record<string, string>): Promise<void> {
  for (let [file, text] of Object.entries(files)) {
    await mkdir(path.dirname(path.join(root, file)), { recursive: true })
    await writeFile(path.join(root, file), text)
  }
  // Files modified in the millisecond a run starts count as changed during it.
  await setTimeout(5)
}

async function createProject(files: Record<string, string>): Promise<string> {
  let root = await realpath(await mkdtemp(path.join(tmpdir(), 'mootant-bug-')))
  roots.push(root)
  await mkdir(path.join(root, 'node_modules'))
  await symlink(
    await realpath(path.resolve(import.meta.dirname, '../../node_modules/vitest')),
    path.join(root, 'node_modules/vitest'),
  )
  await write(root, { 'package.json': '{ "type": "module" }', ...files })
  return root
}

function run(root: string, cache = true): Promise<RunResult> {
  return runMutants({
    builtIns: createBuiltIns('vitest', vitestAdapter()),
    paths: ['src'],
    concurrency: 1,
    cwd: root,
    cache,
  })
}

function verdicts(result: RunResult): Record<string, string> {
  return Object.fromEntries(
    result.results.map(entry => [entry.mutant.replacement, entry.status]),
  )
}

afterEach(async () => {
  await Promise.all(roots.splice(0).map(root => rm(root, { recursive: true, force: true })))
})

describe('BUG-402', () => {
  it('follows the imports of a virtual module', async () => {
    let node = (id: string) => ({
      file: id.startsWith('/') ? id : null,
      importedModules: new Set<object>(),
      transformResult: {},
      url: `url:${id}`,
      id,
    })
    let test = node('/p/test/a.test.ts')
    let virtual = node('\0virtual:limits')
    virtual.importedModules.add(node('/p/limits.json'))
    test.importedModules.add(virtual)
    let known = new Map<string, object>([[test.id, test], [virtual.id, virtual]])
    let project = {
      vite: {
        environments: {
          ssr: {
            moduleGraph: { getModuleById: (id: string) => known.get(id) },
            transformRequest: () => Promise.resolve({}),
          },
        },
      },
    } as unknown as TestProject

    await expect(
      collectDependencies({
        reported: [test.id, virtual.id],
        file: '/p/test/a.test.ts',
        tsconfigs: new Map(),
        project,
      }),
    ).resolves.toContain('/p/limits.json')
  })

  it('runs the mutants again when the file behind a virtual module changes', async () => {
    let root = await createProject({
      'vitest.config.ts': [
        "import { readFileSync } from 'node:fs'",
        "import path from 'node:path'",
        "import { defineConfig } from 'vitest/config'",
        'export default defineConfig({',
        '  plugins: [{',
        "    name: 'limits',",
        "    resolveId: id => (id === 'virtual:limits' ? '\\0virtual:limits' : null),",
        '    load(id) {',
        "      if (id !== '\\0virtual:limits') return null",
        "      let file = path.resolve(import.meta.dirname, 'limits.json')",
        '      this.addWatchFile(file)',
        "      return `export default ${readFileSync(file, 'utf8')}`",
        '    },',
        '  }],',
        "  test: { include: ['test/**/*.test.ts'] },",
        '})',
      ].join('\n'),
      'test/math.test.ts': [
        "import { expect, it } from 'vitest'",
        "import limits from 'virtual:limits'",
        "import { isAdult } from '../src/math'",
        "it('isAdult', () => {",
        '  expect(isAdult(limits.age)).toBe(true)',
        '  expect(isAdult(5)).toBe(false)',
        '})',
      ].join('\n'),
      'src/math.ts': 'export function isAdult(age: number): boolean {\n  return age >= 18\n}\n',
      'limits.json': '{ "age": 30 }',
    })
    await run(root)
    await write(root, { 'limits.json': '{ "age": 18 }' })

    let cached = await run(root)
    let fresh = await run(root, false)

    expect(verdicts(cached)).toStrictEqual(verdicts(fresh))
  }, 120_000)
})
```

## Ожидаемое поведение

После правки `limits.json` вердикты второго прогона совпадают с прогоном
`--no-cache`: `age > 18` — `Killed`, `age == 18` — `Survived`. Файл,
объявленный плагином через `addWatchFile` для виртуального модуля, входит в
`DryFile.dependencies` теста, который этот модуль импортирует.

## Фактическое поведение

```
- Expected
+ Received
  {
-   "age == 18": "Survived",
-   "age > 18": "Killed",
+   "age == 18": "Killed",
+   "age > 18": "Survived",
    "age >= 17": "Survived",
  }
```

Оба вердикта взяты из кэша (`cached: true`), диагностики нет. Unit-тест:
`expected [ '/p/test/a.test.ts', … ] to include '/p/limits.json'`. Контроль: тот
же плагин, трансформирующий **реальный** модуль с `addWatchFile`, работает
правильно — правка файла инвалидирует кэш.

## Подозреваемые места в коде

- `adapters/vitest/collect-dependencies.ts:121-124` — фильтр
  `add(imported.file ?? imported.id ?? '')` одновременно решает «добавить файл»
  и «обходить ли узел»; виртуальный узел отбрасывается вместе со всем, что он
  импортирует. Нужно обходить узлы без файла (кроме `node_modules`), не
  добавляя их самих в список, с защитой от циклов через `seen`.
- `adapters/vitest/collect-dependencies.ts:131-134` — то же для корней из отчёта
  воркера: виртуальный id из `evaluatedModules` не ищется в графе.
- `adapters/vitest/get-module-file.ts:17-20` — правило «абсолютный путь вне
  `node_modules`» верно для того, что попадает в список, но не годится как
  условие обхода.
- `test/adapters/vitest/collect-dependencies.test.ts` — существующий тест
  проверяет, что виртуальные модули не попадают в список; его стоит дополнить
  проверкой, что их импорты попадают.

## Критерий готовности

- Появляется тест в `test/adapters/vitest/collect-dependencies.test.ts`
  (виртуальный модуль из отчёта и виртуальный модуль в середине графа: их
  реальные импорты, в том числе файлы из `addWatchFile`, есть в результате;
  сами виртуальные id — нет; цикл через виртуальный модуль не зацикливает обход)
  и интеграционный тест в `test/adapters/vitest/index.test.ts` по образцу
  второго теста выше. Оба падают до исправления и проходят после.
- `pnpm test` полностью зелёный (включая 100% coverage, `test:js`,
  `test:types`, `test:usage`, `test:spelling`).
- Время подготовки кэша на `test/fixtures/cache*` не растёт заметно: обход
  остаётся линейным по числу узлов графа.
