# BUG-507: под Vitest модули, загруженные через `require()`, не переключаются — ложные NoCoverage

> Самодостаточный промпт для отдельной сессии Claude Code в репозитории
> azat-io/mootant. Серьёзность: high. Статус: подтверждён. Найдено на коммите
> 170ec52.

## Контекст

Vitest-адаптер подменяет текст мутированных файлов только в `transform`-хуке
своего Vite-плагина (`adapters/vitest/create-mootant-plugin.ts:32-50`).
Модуль, который загружает сам Node через `require()` — из CommonJS-исходника,
обслуженного Vite (`a.cjs` требует `b.cjs`), или через `createRequire` в тесте —
Vite не видит. mootant печатает предупреждение `never-served` и ставит всем
мутантам такого файла вердикт NoCoverage, хотя тесты их убивают. Для
CommonJS-кодовой базы под Vitest это занижает score и прячет реальные
выжившие/убитые мутанты. Документация обещает `.cjs` в «List and run mutants»
(`docs/content/guide/compatibility.mdx:34`). Адаптер node:test решает ту же
задачу патчем `Module.prototype._compile`
(`adapters/node-test/preload/patch-module-compile.ts:14`,
`adapters/node-test/preload/install-module-hooks.ts:76`).

## Воспроизведение

Падающий тест в ветке `experiment/bug-repros`: `test/repros/BUG-507.test.ts` и
фикстура `test/repros/BUG-507/`:

```js
// test/repros/BUG-507/src/a.cjs
const { isAdult } = require('./b.cjs')

function canVote(age) {
  return isAdult(age)
}

module.exports = { canVote }

// test/repros/BUG-507/src/b.cjs
function isAdult(age) {
  return age >= 18
}

module.exports = { isAdult }

// test/repros/BUG-507/test/a.check.js
import { expect, it } from 'vitest'

import { canVote } from '../src/a.cjs'

it('lets 18-year-olds vote', () => {
  expect(canVote(18)).toBe(true)
  expect(canVote(17)).toBe(false)
})
```

`vitest.config.ts`: `export default { test: { include: ['test/**/*.check.js'] } }`,
`package.json`: `{ "name": "bug-507-fixture", "private": true, "type": "module",
"scripts": { "test": "vitest --run" } }`.

```ts
// test/repros/BUG-507.test.ts
import { describe, expect, it } from 'vitest'
import path from 'node:path'

import { createBuiltIns } from '../helpers/create-built-ins'
import { vitestAdapter } from '../../adapters/vitest/index'
import { runMutants } from '../../core/run-mutants'

let root = path.resolve(import.meta.dirname, 'BUG-507')

describe('BUG-507: Vitest and modules loaded with require()', () => {
  it('decides the mutants of a module that a source loads with require()', async () => {
    let result = await runMutants({
      builtIns: createBuiltIns('vitest', vitestAdapter()),
      paths: ['src'],
      concurrency: 1,
      cache: false,
      cwd: root,
    })
    let verdicts = result.results
      .filter(verdict => verdict.mutant.file === 'src/b.cjs')
      .map(verdict => `${verdict.mutant.replacement} ${verdict.status}`)

    expect(verdicts).toContain('age > 18 Killed')
  }, 60_000)
})
```

```bash
pnpm vitest --run test/repros/BUG-507.test.ts
```

## Ожидаемое поведение

Мутанты `src/b.cjs` переключаются так же, как у импортируемого модуля:
`age >= 18 -> age > 18` — Killed (физически применённый мутант роняет тест),
`age >= 18 -> age == 18` — Survived.

## Фактическое поведение

```
AssertionError: expected [ 'age > 18 NoCoverage', …(4) ] to include 'age > 18 Killed'
```

CLI на той же фикстуре: `! src/b.cjs: No test loaded src/b.cjs through the test
runner's transform … [never-served]`, `killed 3, no coverage 5, score 37.5%`.
Физическая проверка (каждый мутант вручную + `vitest --run`): 4 из 5 мутантов
`b.cjs` убиваются. Вариант с `createRequire` в тесте (пакет `"type":
"commonjs"`) — 6 из 7 расхождений, и тест-файл даже не выбирается в dry run.

## Подозреваемые места в коде

- `adapters/vitest/create-mootant-plugin.ts:32-50` — единственная точка
  переключения: Vite `transform`.
- `adapters/vitest/runner.ts` — раннер воркера; сюда можно поставить
  `patchModuleCompile` (как в `adapters/node-test/preload/install-module-hooks.ts:76`),
  чтобы переключать CJS-модули, которые грузит `require()`, и отмечать их
  как served.
- `core/run/read-test-imports.ts`, `core/run/rank-test-file.ts` — выбор
  тест-файлов по статическим импортам: `createRequire(...)('../src/x')` не
  учитывается (тест не выбирается).
- `docs/content/guide/compatibility.mdx:34,56-57` — до исправления описать
  ограничение.

## Критерий готовности

- Тест в `test/adapters/vitest/` (по образцу `test/adapters/vitest/index.test.ts`,
  можно сравнение с ручным применением через `test/helpers/run-reference-mutants.ts`)
  на CJS-цепочке `a.cjs → require('./b.cjs')`: вердикты совпадают с ручным
  применением; падает до исправления, проходит после. Воспроизведение
  `test/repros/BUG-507.test.ts` проходит.
- Предупреждение `never-served` для `b.cjs` больше не выдаётся.
- `pnpm test` полностью зелёный (включая 100% coverage, `test:js`,
  `test:types`, `test:usage`, `test:spelling`).
