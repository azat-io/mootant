# BUG-104: switched-текст растёт квадратично с размером литерала

> Самодостаточный промпт для отдельной сессии Claude Code в репозитории
> azat-io/mootant. Серьёзность: medium. Статус: подтверждён.
> Найдено на коммите 170ec52.

## Контекст

Mootant хостит мутанты текстом: каждый replacement вставляется в switched-файл
целиком рядом с оригиналом (`core/instrument/render-mutant-range.ts:85-95`,
`(check ? (replacement) : (original))`). Мутаторы `object-property` и
`array-element` удаляют один элемент литерала, но их replacement — это весь
литерал без одного элемента. Для литерала из N элементов switched-текст
содержит N копий литерала: размер O(N²). Ограничений нет ни при генерации, ни
в `instrumentFile` (`core/instrument/instrument-file.ts:51-76`), ни в
`createSwitchedFiles` (`core/instrument/create-switched-files.ts:63-107`).
Тот же объём попадает в отчёт `list --json` (каждый мутант несёт
replacement, `--verbose` ещё и original), а в `mootant run` — в модуль,
который Vite трансформирует и V8 компилирует в каждом воркере.

Это не теоретический случай: в компиляторе Svelte
`packages/svelte/src/compiler/phases/1-parse/utils/entities.js` — объект из
2231 записи `'name;': codePoint` (41 КБ).

## Воспроизведение

Юнит-тест `test/repros/BUG-104.test.ts` (ветка `experiment/bug-repros`),
падает на 170ec52 (`expected 3359222 to be less than 415400`):

```ts
import { describe, expect, it } from 'vitest'

import { instrumentFile } from '../../core/instrument/instrument-file'
import { generateMutants } from '../helpers/generate-mutants'

describe('BUG-104: the switched text grows with the square of a literal', () => {
  it('keeps the switched text of a lookup table within a linear bound', () => {
    let entries = Array.from(
      { length: 400 },
      (_, index) => `  'entity${index};': ${index + 100},`,
    )
    let source = ['export default {', ...entries, '}'].join('\n')
    let file = 'entities.js'
    let mutants = generateMutants(source, { preset: 'strict', file })
    let switched = instrumentFile({ mutants, source, file })

    expect(
      mutants.filter(mutant => mutant.mutator === 'object-property').length,
    ).toBeGreaterThan(0)
    expect(switched.length).toBeLessThan(50 * source.length)
  })
})
```

Замер на реальном файле (скрипт `analysis/tools/instrument/switch-size.mjs`
ветки `analysis/2026-11`; Node 22.23.4, oxc из пакета):

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/sveltejs/svelte.git
cd svelte && git sparse-checkout set packages/svelte/src
mootant list packages/svelte/src/compiler/phases/1-parse/utils/entities.js \
  --json --verbose --preset strict | wc -c
```

## Ожидаемое поведение

Размер switched-текста и отчёта линеен по размеру файла (с разумной
константой), либо Mootant явно ограничивает число/объём таких мутантов и
сообщает об этом (skip с причиной), а не строит модуль в сотни мегабайт.

## Фактическое поведение

`entities.js` (41 289 байт) под `--preset strict`: 4462 мутанта (2231
`object-property` + 2231 `number-literal`), `list --json --verbose` печатает
418 754 527 байт за 56 с, switched-текст — 92 100 466 байт (рост ×2231),
`transformWithOxc` switched-текста — 13 с, пик RSS процесса — 3,9 ГБ.
Весь `packages/svelte/src` (380 файлов): `list --json` — 238 МБ,
`--verbose` — 461 МБ, 86 с, 3 ГБ RSS. Под `recommended` объектные мутанты в
этом файле не создаются, но тот же рост даёт массив/объект с элементами без
вложенных мутантов (массив из 1000 элементов-вызовов `fnN()`: 9,0 МБ switched из 40,7 КБ исходника, `list --json --verbose` — 36 МБ).

## Подозреваемые места в коде

- `core/mutators/object-property.ts`, `core/mutators/array-element.ts` —
  replacement = весь литерал без элемента.
- `core/instrument/render-mutant-range.ts:85-95` — каждый replacement
  вставляется целиком.
- `core/instrument/create-switched-files.ts:74-104` — нет бюджета размера
  switched-текста.

Варианты: (1) хостить удаление элемента на уровне элемента (для объекта —
`{ a, ...(check ? {} : { b: 1 }), c }` сохраняет порядок ключей; осторожно с
методами и `super`, геттерами, `__proto__:`; для массива — `[a, ...(check ?
[] : [b]), c]`, осторожно с дырами и `length`); (2) пропускать такие мутанты
для литералов больше K элементов с явной причиной skip; (3) бюджет размера
switched-текста на файл с диагностикой. Вариант (1) требует проверки
эквивалентности с физическим применением (см. дифференциальные тесты в
`test/core/instrument/instrument-file.test.ts`).

## Критерий готовности

- `test/repros/BUG-104.test.ts` (или аналог в `test/core/instrument/`)
  падает до исправления и проходит после.
- Для `entities.js` Svelte под `strict` switched-текст и `list --json` —
  не больше нескольких мегабайт.
- Дифференциальный тест «switched с active=X ≡ физически применённый X»
  (`instrument-file.test.ts`) проходит для программ с литералами, из которых
  удаляются элементы (включая геттеры, методы с `super`, `__proto__`, дыры).
- `pnpm test` полностью зелёный (включая 100% coverage, `test:js`,
  `test:types`, `test:usage`, `test:spelling`).
