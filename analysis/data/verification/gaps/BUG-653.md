5. `pnpm run /^test:/` запускает скрипты параллельно и после первого падения убивает остальные (SIGKILL), поэтому их статус не виден.
6. Критерий «pnpm test полностью зелёный» на перегруженной машине без оговорок не выполнить:

   - полный прогон занимает около 28 минут.
