## Пробелы промпта (воспроизводящий агент)

1) Воспроизведение есть только по сети (GitHub main). Сейчас main==170ec52, но как только upstream сдвинется, команда перестанет отражать исследуемый коммит. Нужна и проверка без исполнения: `git ls-tree -r --name-only 170ec52 | grep -E '(^|/)SKILL\.md$'` (пусто).
2) `npx skills@…` исполняет внешний код. В песочнице его может заблокировать политика прав, как и случилось здесь. Нет запасного пути: статической проверки или ссылки на функции discoverSkills/parseSkillMd в dist/cli.mjs.

4) BUG-650 и BUG-652 упомянуты без сути:
 - для BUG-652 не сказано, что поле recheck содержит `mootant run … --mutant …` без `npx` (видно в skill-session.ansi);

6) Критерий «каждый --флаг есть в parserOptions» не учитывает два обстоятельства:
 - parserOptions не экспортирован (`let` в cli/parse-arguments.ts:64), а экспорт заденет knip;
 - parseArgs работает с allowNegative: true, поэтому тест должен понимать --no-cache, --no-html, --no-incremental.
7) Замена на `--skill mootant` указана только для getting-started.mdx, хотя та же команда стоит в docs/components/Skill.astro:39 (главная страница).
