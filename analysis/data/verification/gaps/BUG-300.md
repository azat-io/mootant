2) Не сказано, откуда взять `/path/to/mootant-0.1.0.tgz` (нужно `pnpm build && pnpm pack`, в `files` только bin и dist). В package.json фикстуры analysis/data/skips/fx1 путь `file:../../../artifacts/...` с её места в репозитории указывает на несуществующий analysis/artifacts/. 4) Промпт не упоминает приёмочную фикстуру `test/fixtures/list/expected-skipped.json` (её читает `test/cli/index.test.ts`). 5) В `docs/content/mutators/array-element.md:136` как пример законного пропуска solitary приведён именно случай бага: `['card', 'paypal']` → `['paypal']`. Пример нужно заменить на нестроковый; промпт говорит только «обновить таблицы».

6) Ограничения дизайна не объяснены:
   - `countsForSolitary` задаётся для всего мутатора (`types/mutator/mutator-meta.d.ts:11`), поэтому «`countsForSolitary: false` для элементов коллекций» без нового механизма невозможно.

Узкий вариант (а) выражается через `inner.start === range.start && inner.end === range.end` плюс id мутатора (хардкод в общем пайплайне) либо через новое необязательное поле в публичном `types/mutator/replacement.d.ts`.
   - Вариант (в) `coarseMutants: 'partial'` меняет формат конфига: настройка булева (`types/config/preset-settings.d.ts:29`, проверка в `core/plugins/get-settings-problem.ts:14`). Это противоречит разделу «Ограничения», а промпт об этом не предупреждает.

7) Область исправления размыта. В мотивации названы 980 удалений свойств, но вариант (а) покрывает только массивы, и в нём 1486 из 2028 случаев (542 — вложенные массивы, объекты и т.п.). У свойств 747 из 980 случаев имеют вид `key: 'строка'`. Если трогать и свойства, сломаются примерно 15 ожиданий `(subsumed solitary)` в `test/core/mutators/object-property.test.ts` (например, `{ type: 'cardinal' } -> {}`).

9) Утверждения про perfectionist («13 из 81») и «core, 90 пропусков solitary — 0 скрытых» по промпту не проверить: нет коммита и пути клона, ссылка ведёт на analysis/bugs/skips.md. При этом «90» конфликтует с 5476 пропусками solitary в `list core --skipped`: видимо, это выборка, и это стоит сказать явно.
