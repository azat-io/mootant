# Agent skill

[`mootant`](mootant/SKILL.md) is an agent skill for Claude Code, Codex, Cursor
and other agents. It reads the report, writes the missing tests and asks Mootant
to confirm each kill.

```sh
npx skills add azat-io/mootant
```

See [mootant.org/agent-skill](https://mootant.org/agent-skill).
